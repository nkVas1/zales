# Художественное направление · «Чаща»

> Вы стоите на краю непроходимого леса. Рядом — тяжёлый рубильник на керамическом
> основании. Вы опускаете рукоять, где-то щёлкает контакт, и чаща перед вами
> расступается просекой.

Это не иллюстрация к приложению. Это и есть приложение: один предмет, один лес и
одно состояние, читаемое с двух метров.

---

## 1. Три источника

| Источник | Что берём |
| --- | --- |
| **Русская чаща** | Плотность, глубина, ощущение непроходимости. Лес — это состояние блокировки, а не декорация |
| **Ретро-приборы** | Карболитовая рукоять, латунные контакты, гравированные шильдики, надписи «ВКЛ / ВЫКЛ». Вещь, сделанная, чтобы служить сорок лет |
| **Фольклор и резьба** | Пропильная резьба северных наличников как 1-битный орнамент. Присказки вместо системных сообщений. Тепло без умиления |

Соединяет их **дизеринг**: и лес, и предмет, и даже шрифт живут в двух-трёх тонах,
собранных упорядоченной матрицей Байера. Это техника гравюры, ранних экранов и
типографского растра одновременно — и именно она задаёт всему единый материал.

## 3. Палитра

Дизайн строится на **одной цветной сущности**. Всё остальное — два тона.

### Тёмная тема — ночной лес (основная)

```
--void        #070A08   чернота чащи, фон
--deep        #0D1310   ближний план леса
--mid         #16201B   просека, поверхность
--moss        #2A3A30   разделители, неактивное
--fog         #6E7A72   второстепенный текст
--birch       #E8E3D6   основной текст, кость и береста
--copper      #B87333   латунь контактов
--ember       #E0762A   СИГНАЛ: открыто
--ember-hot   #FF8A3D   искра, ровно один кадр
--rust        #A33A22   тревога, скупо и приглушённо
```

### Светлая тема — бумага и оттиск

```
--paper       #EDE8DC   бумага
--paper-2     #DDD6C6   тень на бумаге
--ink         #14100C   краска
--ink-soft    #4A443A   второстепенный текст
--copper / --ember / --rust  те же
```

**Дисциплина цвета.** `--ember` появляется только там, где идёт ток: рукоять во
включённом положении, просека, живой индикатор трафика. Ни заголовков, ни кнопок,
ни иконок этим цветом. Когда всё выключено, на экране нет ни одного цветного пикселя —
поэтому включение читается мгновенно.

`--rust` никогда не заливает экран и не мигает. Тревога у нас — это приглушённый
сигнал, а не паника.

## 4. Дизеринг как материал

Ядро визуальной системы — шейдер `ThicketShader` на AGSL.

**Что он делает.** Берёт поле плотности леса (fBm-шум с анизотропией по вертикали —
получаются стволы), применяет упорядоченный дизеринг матрицей Байера 8×8 и квантует
результат в два тона. Порог дизеринга анимируется — и лес расступается.

```glsl
// ядро: порядковый дизеринг с анимируемым порогом
half bayer8(int2 p) { /* нормированная матрица 8×8 */ }

half4 main(float2 frag) {
    float2 uv = frag / uResolution;
    float  density = thicketField(uv, uTime);        // fBm со стволами
    float  clearing = smoothstep(uOpen - 0.28, uOpen + 0.28, distToPath(uv));
    float  value = density * clearing;
    half   threshold = bayer8(int2(frag) % 8) + uGrain;
    return value > threshold ? uInk : uPaper;        // ровно два тона
}
```

**Единицы измерения.**

| Параметр | Диапазон | Что значит |
| --- | --- | --- |
| `uOpen` | 0.0 → 1.0 | 0 — глухая чаща, 1 — открытая просека |
| `uBreath` | 0.0 → 1.0 | Амплитуда медленного дыхания леса |
| `uPulse` | всплеск | Живой трафик: рябь по краям просеки |
| `uGrain` | 0.03 → 0.05 | Зерно, оно же спасает от бандинга |

**Запасной путь для Android 8–12** (нет `RuntimeShader`): поле леса рендерится в
`Bitmap` один раз на нескольких уровнях `uOpen`, порог применяется через
`ColorMatrix`-квантование. Визуально беднее, но узнаваемо то же самое, и главное —
кадры не проседают.

**Дизеринг работает и на типографике.** Крупное слово состояния растеризуется той же
матрицей. Ни одного отдельного «эффекта» — один материал на весь экран.

## 5. Рубильник

Главный и единственный орган управления. Он должен ощущаться как предмет, у которого
есть вес.

**Устройство.** Керамическое основание (`--birch` в дизеринге), карболитовая рукоять
тёмно-вишнёвого тона, латунные ножевые контакты, гравированные подписи «ВЫКЛ» сверху и
«ВКЛ» снизу шрифтом JetBrains Mono — как на щитке подстанции.

**Физика.** Не анимация по кривой, а симуляция:

| Свойство | Значение | Зачем |
| --- | --- | --- |
| Масса рукояти | условные 0.8 | Инерция при отпускании на полпути |
| Пружина возврата | stiffness 380, damping 0.72 | Недоведённая рукоять честно падает обратно |
| Защёлка | последние 18 % хода | Проходится рывком — «щёлк», обратной дороги нет |
| Трение | 0.12 | Рукоять не скользит как по льду |
| Порог срабатывания | 72 % хода | Случайное касание ничего не включает |

**Взаимодействие.** Два одинаково законных способа:

1. **Потянуть** рукоять вниз пальцем — для тех, кому нравится трогать вещи.
2. **Нажать и подержать** 400 мс — рукоять пойдёт вниз сама. Это путь для дедушки:
   не нужно ни целиться, ни тащить.

Одиночное короткое касание **не включает** — вместо этого рукоять чуть вздрагивает и
внизу появляется подсказка «потяните вниз или задержите палец». Один раз показали —
человек понял навсегда.

**Замыкание.** В момент прохождения защёлки: один кадр `--ember-hot` в точке контакта,
затем трёхкадровое дизеренное затухание. Никаких лучей и бликов — просто искра.

## 6. Гаптика

Тактильность — половина ощущения предмета. Через `VibrationEffect.Composition`, с
деградацией на старых устройствах.

| Момент | Отклик |
| --- | --- |
| Палец лёг на рукоять | `PRIMITIVE_LOW_TICK`, интенсивность 0.3 |
| Рукоять идёт по ходу | Серия `LOW_TICK` каждые 12 % хода — ощущается как насечки |
| Защёлка сработала | `PRIMITIVE_QUICK_RISE` 0.6 → `PRIMITIVE_THUD` 1.0 |
| Тропа открылась | Двойной глухой `THUD` 0.5, пауза 90 мс |
| Тропа сузилась | Одиночный `LOW_TICK` 0.4 — предупреждение, не тревога |
| Отказ | `PRIMITIVE_SPIN` 0.4 — ощущается как «не пошло», без агрессии |

Гаптика подчиняется системным настройкам и полностью отключается вместе с ними.

## 7. Типографика

| Роль | Гарнитура | Почему |
| --- | --- | --- |
| Интерфейс | **Golos Text** (SIL OFL) | Сделана Paratype и «Сменой» для государственных сервисов — то есть буквально спроектирована под читателя, который не хочет разбираться. Кириллица родная, не «латиница с добавками» |
| Приборные надписи, числа | **JetBrains Mono** (SIL OFL) | Моноширинная кириллица для шильдиков, задержки, трафика, версии сборки |
| Логотип | **Собственная отрисовка** | «ZALES» с резными засечками — вырезано вручную, вектором, не шрифтом |

**Шкала — «сначала дедушка».** Базовый размер 18sp, а не 14sp. Ниже 16sp текста в
приложении не существует вообще.

```
Состояние      64sp / Black / трекинг +0.04em / дизеринг
Заголовок      28sp / Bold
Основной       18sp / Regular / межстрочный 1.5
Подпись        16sp / Medium / --fog
Шильдик        14sp / JetBrains Mono / --moss  ← единственное исключение, только для
                                                 технических данных, не для инструкций
```

Приложение уважает системное увеличение шрифта до 200 % — без обрезаний и наложений.

## 8. Композиция

Один столбец, поля 24 dp. Экран делится не поровну, а **оптически**:

```
┌──────────────────────────────┐
│  ◣ орнамент          ▣ шильдик │   верхняя строка: 8 % высоты
│                              │
│                              │
│         Ч А Щ А              │   лес: 46 %, дышит, живёт
│      (фон во весь экран)     │
│                              │
│        З А К Р Ы Т О         │   слово состояния: оптический центр
│                              │
│           ╔═══╗              │
│           ║   ║  рубильник   │   орган управления: 30 %,
│           ╚═╤═╝              │   центр тяжести на 38 % снизу
│          ══╧══               │
│                              │
│   «в лесу тихо, но мы шумим» │   приговорка: 16 %, мелко, --fog
│  ◤ орнамент          ◥       │
└──────────────────────────────┘
```

Рубильник стоит **не в геометрическом центре**, а на 38 % от нижнего края — так предмет
выглядит стоящим, а не парящим. Слово состояния над ним, а не под: сначала читаешь, что
происходит, потом видишь, чем управлять.

Фольклорный орнамент — четыре угловые метки по мотивам пропильной резьбы, 1-битные,
размером 16 dp. Это рамка, а не картинка: заметишь, только если присмотришься.

## 9. Состояния

| Состояние | Лес | Слово | Рубильник | Цвет |
| --- | --- | --- | --- | --- |
| Закрыто | Глухая чаща, `uOpen` 0.0, медленное дыхание | ЗАКРЫТО | Вверху, латунь холодная | Ни одного цветного пикселя |
| Открываю | Порог поплыл, `uOpen` 0.0 → 0.45, рябь | ИЩУ ТРОПУ | Внизу, контакт замкнут | Искра погасла, тлеет `--copper` |
| Открыто | Просека, `uOpen` 1.0, край дышит от трафика | ОТКРЫТО | Внизу | `--ember` в контактах и по краю просеки |
| Сузилась | `uOpen` 0.55, лес подступает | ТРОПА СУЗИЛАСЬ | Внизу, дрожит | `--ember` тускнеет до `--copper` |
| Не вышло | Чаща сомкнулась резко | НЕ ПРОШЛИ | Вверху, отброшен | `--rust` только в подписи |

Ни на одном экране нет ни спиннера, ни прогресс-бара. Ожидание показывается тем, как
расступается лес.

## 10. Движение

**Только пружины.** Ни одной анимации по длительности и кривой.

| Схема | stiffness | damping | Где |
| --- | --- | --- | --- |
| Тяжёлая | 380 | 0.72 | Рубильник, крупные предметы |
| Мягкая | 220 | 0.85 | Появление панелей, списки |
| Дыхание | 12 | 1.0 | Лес, бесконечное медленное движение |

**Переходы между экранами — растворение по порогу дизеринга.** Уходящий экран
рассыпается в растр, приходящий из растра собирается. Ни одного `fadeIn`/`fadeOut`
во всём проекте — это записано в правилах ревью.

При включённом системном уменьшении движения лес замирает, растворение становится
мгновенным, физика рубильника сокращается до одного шага. Приложение остаётся полностью
рабочим.

## 11. Звук

По умолчанию **выключен**. Кто включит — получит ровно три звука, синтезированных, а не
записанных: щелчок защёлки, глухой удар замыкания, короткий шорох при отказе. Подчиняются
беззвучному режиму и громкости уведомлений.

---

## 12. Иконка

Рукоять рубильника во включённом положении, 1-битная, `--ember` на `--void`. Читается на
48 px, узнаётся среди сотни иконок на рабочем столе Samsung. Адаптивная иконка: передний
план — рукоять, фон — дизеренная чаща. Монохромная версия для тем Android 13+.

---

## 13. Рабочий процесс дизайнера

1. Сначала полностью проходим код экрана: убираем лишние блоки, старые палитры, мёртвые
   ветки тем, чужие иконки.
2. Только после всех правок — визуальная проверка на устройстве.
3. Важные снимки после структурных изменений уходят в `design-archive/` с датой и
   номером фазы. Рабочие черновики — в `scratch/`, который не попадает в репозиторий.
