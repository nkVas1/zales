# Диагностика: как отказ становится понятной фразой

Пользователь никогда не видит кода ошибки. Он видит одно предложение о том, что
случилось, и **одно** действие. Всё остальное спрятано в разделе для того, кто дал ключ.

---

## 1. Лестница проб

Диагностика идёт снизу вверх и останавливается на первом провалившемся шаге. Это
экономит время и, что важнее, даёт **однозначный** диагноз вместо списка гипотез.

```
П1  Телефон вообще в сети?              → сетевой интерфейс, любой отклик
П2  Имя заставы разрешается?            → DNS, сравнение с эталонным резолвером
П3  До заставы достучаться можно?       → TCP-соединение на порт, замер времени
П4  Транспорт поднимается?              → TLS / Reality / XHTTP рукопожатие
П5  Застава нас узнаёт?                 → авторизация протокола
П6  Данные реально ходят?               → HTTP-запрос сквозь туннель
П7  Ходят с приемлемой скоростью?       → пропускная способность, стабильность
```

Каждый шаг имеет бюджет времени. Вся проверка укладывается в 12 секунд, иначе человек
решит, что приложение зависло.

## 2. Таксономия отказов

`Код` — только для технического отчёта. `Фраза` — то, что видит человек. `Действие` —
единственная кнопка под фразой.

### Проблемы на стороне телефона

| Код | Что произошло | Фраза | Действие |
| --- | --- | --- | --- |
| `NET-01` | Нет ни одного сетевого интерфейса | Телефон сейчас не в сети. Включите Wi-Fi или мобильный интернет. | Открыть настройки сети |
| `NET-02` | Есть сеть, но нет выхода наружу | Wi-Fi подключён, но интернета за ним нет. Так бывает в гостиницах и кафе — нужно открыть страницу входа. | Открыть страницу входа |
| `NET-03` | Режим полёта | Включён режим полёта. | Выключить режим полёта |
| `SYS-01` | Пользователь не выдал разрешение на VPN | Android спрашивает разрешение — без него я не смогу открыть тропу. Это обычное системное окно. | Показать окно снова |
| `SYS-02` | Другой VPN уже занял канал | Сейчас работает другое VPN-приложение. Одновременно может быть только одно. | Показать, какое именно |
| `SYS-03` | Samsung усыпил приложение | Телефон отправил меня в спящий режим, поэтому связь оборвалась. Это лечится один раз и навсегда. | Провести по шагам |
| `SYS-04` | Экономия батареи убивает соединение | Из-за экономии заряда телефон обрывает мою работу в фоне. | Разрешить работу в фоне |

### Проблемы с ключом

| Код | Что произошло | Фраза | Действие |
| --- | --- | --- | --- |
| `KEY-01` | Не разбирается ни одним парсером | Я не смог прочитать этот ключ. Похоже, он скопирован не целиком. | Вставить заново |
| `KEY-02` | Формат знаком, но полей не хватает | В ключе не хватает адреса заставы. Попросите прислать его ещё раз. | Скопировать текст просьбы |
| `KEY-03` | Динамический ключ Outline не отдаёт конфигурацию | Ключ ведёт на страницу, которая сейчас не отвечает. Обычно это временно. | Попробовать снова |
| `KEY-04` | Протокол не поддерживается этой версией | Этот ключ работает по способу, которого я пока не умею. | Показать, что за способ |
| `KEY-05` | Ключа нет вообще | Ключа пока нет. Вставьте его — это единственное, что нужно. | Вставить ключ |

### Проблемы с заставой

| Код | Что произошло | Фраза | Действие |
| --- | --- | --- | --- |
| `SRV-01` | DNS не разрешает имя заставы | Не могу найти заставу по её имени. Возможно, провайдер портит справочник адресов. | Попробовать обход |
| `SRV-02` | TCP-соединение отвергнуто | Застава отвечает, что этот вход закрыт. Скорее всего, на сервере что-то поменялось. | Отправить отчёт владельцу |
| `SRV-03` | TCP-соединение по тайм-ауту | Застава не отвечает. Или она выключена, или до неё не пускают. | Проверить ещё раз |
| `SRV-04` | Рукопожатие отклонено | Застава не приняла рукопожатие. Обычно так бывает, когда на сервере обновили настройки, а ключ остался старый. | Запросить новый ключ |
| `SRV-05` | Авторизация не прошла | Застава меня не узнала. Ключ, скорее всего, отозван или истёк. | Запросить новый ключ |
| `SRV-06` | Сертификат не сходится | Что-то встало между мной и заставой и подменяет себя за неё. Соединяться небезопасно. | Показать подробности |

### Проблемы блокировки

| Код | Что произошло | Фраза | Действие |
| --- | --- | --- | --- |
| `DPI-01` | Все стратегии провалились на рукопожатии | Ваша сеть сегодня не пропускает этот способ связи. Я перебрал все известные мне обходы. | Показать, что можно поменять на сервере |
| `DPI-02` | Обнаружена заморозка сессии | Провайдер придушивает соединение после первых килобайт. Перехожу на способ, который это обходит. | *(без кнопки, чинится само)* |
| `DPI-03` | Работает, но очень медленно | Тропа открыта, но узкая — провайдер замедляет. Попробую найти путь пошире. | *(без кнопки, чинится само)* |
| `DPI-04` | Работает только в Wi-Fi, не в мобильной сети | У вашего оператора этот способ не проходит, а по Wi-Fi всё в порядке. | Показать, что просить у владельца |

### Внутренние сбои

| Код | Что произошло | Фраза | Действие |
| --- | --- | --- | --- |
| `INT-01` | Ядро не запустилось | Что-то сломалось у меня внутри. Это моя вина, не ваша. | Перезапустить |
| `INT-02` | Нативная библиотека не подошла к устройству | Эта сборка не подходит вашему телефону. Нужна другая версия приложения. | Открыть страницу загрузки |
| `INT-03` | Хранилище ключа недоступно | Не могу открыть хранилище ключей. Так бывает после смены блокировки экрана. | Вставить ключ заново |

## 3. Правила написания фраз

Всякая новая запись таксономии проходит эти проверки:

1. **Читается вслух за 5 секунд.** Не читается — переписать.
2. **Ни одного технического термина.** «Рукопожатие» допустимо: слово обиходное и
   образное. «Handshake», «TLS», «сертификат X.509» — нет.
3. **Указана вероятная причина, а не список возможных.** Мы выбираем самую вероятную и
   называем её. Если ошиблись — человек нажмёт «проверить ещё раз».
4. **Виноват не пользователь.** Формулировка никогда не начинается со слова «вы».
5. **Ровно одно действие.** Если хочется двух — значит, диагноз недостаточно точный.
6. **Никаких приговорок рядом.** Экран отказа — зона без шуток (см. [VOICE.md](VOICE.md)).

## 4. Экран «Проверка тропы»

Запускается сам при неудаче и вручную из настроек.

```
┌──────────────────────────────┐
│  ПРОВЕРКА ТРОПЫ              │
│                              │
│  ▣  Телефон в сети           │
│  ▣  Застава найдена          │
│  ▣  До заставы достучались   │
│  ◐  Проверяю рукопожатие…    │
│  ·   Проверка связи          │
│  ·   Замер скорости          │
│                              │
└──────────────────────────────┘
```

Шаги проверяются по очереди, у каждого — своя строчка. Видно, докуда дошли и где
споткнулись. Это само по себе успокаивает: человек видит работу, а не бесконечное
вращение.

По завершении — одна фраза диагноза, одна кнопка действия и свёрнутый блок
**«Для того, кто дал ключ»**.

## 5. Технический отчёт

Разворачивается по нажатию, копируется одной кнопкой. Написан по-английски — его
переслать инженеру, а не читать самому.

```
Zales 1.0.0 (build 142) · Android 15 · SM-S928B
Xray-core v26.9.9 · libXray v26.9.9

Key      vless / reality / tcp / xtls-rprx-vision
Server   ***.example.com:443  (resolved 203.0.113.7, direct)
Network  cellular · MCC/MNC 250-01 · LTE

Probe results
  P1 interface        OK    (12 ms)
  P2 dns              OK    (48 ms, matches control resolver)
  P3 tcp connect      OK    (91 ms)
  P4 transport        FAIL  (timeout after 5000 ms)
  P5 auth             SKIPPED
  P6 tunnel http      SKIPPED

Strategies attempted
  S0 baseline                     FAIL  handshake timeout
  S1+S2 fragment+randomized       FAIL  handshake timeout
  S1+S2+S6 no-mux                 FAIL  handshake timeout
  S5 direct-ip                    FAIL  handshake timeout

Verdict  DPI-01 — transport blocked on this network
Hint     Server-side change required: enable XHTTP (packet-up) or
         switch serverName to a domain reachable from RU.
```

**Из отчёта вычищены:** UUID, пароли, полный адрес заставы (остаётся только домен
верхнего уровня и IP), идентификаторы устройства. Перед копированием показывается
предпросмотр — человек видит ровно то, что уйдёт.
