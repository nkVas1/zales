# Zales — контекст проекта

Android VPN-клиент. Пользователь вставляет свой ключ VLESS или Outline и пользуется
туннелем. Настоящий конечный пользователь — пожилой человек, который хорошо видит, но
теряется в интерфейсах. Это главный критерий любого решения по UX.

## Решения, которые не пересматриваются без явной просьбы

- Ядро — только Xray-core через libXray. Не предлагать sing-box для первой версии
  ([ADR-0001](docs/adr/0001-xray-core-only.md)).
- Туннель живёт в отдельном процессе `:tunnel` ([ADR-0004](docs/adr/0004-separate-tunnel-process.md)).
- Нативные артефакты собирает CI, в репозитории бинарников нет ([ADR-0003](docs/adr/0003-single-go-runtime.md)).
- Лицензия MPL-2.0 ([ADR-0005](docs/adr/0005-license-mpl2.md)). Каждый новый исходный
  файл начинается с шапки MPL — копилефт здесь привязан к файлу.
- Художественное направление «Чаща» построено на диссонансе: **холодная враждебная
  чаща снаружи, тёплая обжитая сторожка внутри**, без полутонов между ними. Физический
  рубильник, дизеринг Байера, ретро-фольклорная нота, дозированная жуть. Никакого
  стекла, свечения и градиентов.

## Правила, которые легко нарушить по привычке

1. Никаких `fadeIn`/`fadeOut` — только растворение по порогу дизеринга.
2. Никаких кодов ошибок в интерфейсе — только фраза плюс одно действие.
3. Никаких шуток («приговорок») в состоянии отказа. И никакого регистра «чащи» в
   трудную минуту — жутко бывает, только когда всё хорошо.
4. Текст мельче 16sp запрещён, кроме технического шильдика 14sp.
5. Секрет ключа не поднимается выше `KeyRepository`.
6. `feature/*` не зависит от `tunnel:engine-*`.

## Команды

```powershell
.\gradlew installDebug        # собрать и поставить на телефон
.\gradlew lint detekt test    # ворота качества
adb logcat -s Zales:V ZalesTunnel:V
```

Среда разработки поднимается по [docs/SETUP.md](docs/SETUP.md). Java, Android SDK и Go
на машине изначально отсутствуют.
